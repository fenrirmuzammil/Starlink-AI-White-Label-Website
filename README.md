# Starlink AI — White Label Landing Page

A responsive, animated white-label recreation of the supplied Starlink AI token-deployer landing page.

## Files

- `index.html` — complete page structure and content
- `style.css` — responsive white/blue/purple visual system, glass cards, gradients, waves and animations
- `script.js` — scroll reveal, FAQ accordion behavior, demo modal and small interactions

## Run locally

Just open `index.html` in a browser.

For GitHub Pages:
1. Create a repository.
2. Upload `index.html`, `style.css`, `script.js`.
3. Go to **Settings → Pages**.
4. Select the branch containing these files and the root folder.
5. Save.

## Notes

The artwork is built with CSS gradients, shapes and UI components rather than a low-resolution screenshot, so it remains sharp when zooming. Replace the placeholder token/globe artwork with your own SVG/3D assets later if you want even more visual fidelity.
